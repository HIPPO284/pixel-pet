# PixelPet

A browser-based editor for turning pet photos into pixel characters.

## Features

- Select and refine the subject.
- Customize pixel appearance, accessories, and animation.
- Export PNG images, sprite sheets, and .petpack files.
- Collect user feedback through a Node.js and SQLite backend.

Image editing takes place locally in the browser.

## Technology

HTML, CSS, JavaScript, Canvas, IndexedDB, Node.js, and SQLite.

## Status

An early prototype. The previous Railway demo is currently unavailable.
